# Task 7: Property Listing Website

The Property Listing Website is a simple HTML-based web application designed to display real estate properties along with their specifications and contact information. The website helps users browse available properties, view important details such as price, location, area, and amenities, and contact the property owner or agency for further inquiries.

# Task 8: NGO Awareness Portal

The NGO Awareness Portal is an HTML-based website developed to promote social service activities, awareness campaigns, community programs, and volunteer participation. The portal serves as an information platform where visitors can learn about the NGO's mission, ongoing initiatives, and opportunities to contribute to social causes.
